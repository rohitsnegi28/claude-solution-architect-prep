# Glossary

Use this file to collect important Claude, AI, cloud, and solution architecture terms.

| Term | Meaning | Why It Matters |
| --- | --- | --- |
| Claude | Anthropic's AI assistant/model family. | Core platform for the solution architect preparation. |
| AI Fluency | The ability to collaborate with AI effectively, responsibly, and confidently. | Helps users work with AI beyond basic prompting or tool usage. |
| Human-AI Collaboration | A working model where humans define goals, apply judgment, and stay accountable while AI assists with tasks. | Keeps AI use productive while preserving human responsibility. |
| Automation | Using AI to execute a clear, well-defined task. | Useful for repeatable tasks with clear outcomes. |
| Augmentation | Using AI as a creative or analytical partner. | Supports complex thinking while humans retain judgment. |
| Agency | Allowing AI to act more independently toward a goal under human direction. | Enables advanced workflows but requires strong oversight. |
| Delegation | Deciding what work should be done by humans, AI, or both. | Prevents inappropriate or risky use of AI. |
| Description | Communicating clearly with AI using context, instructions, constraints, and desired output. | Improves output quality and reduces ambiguity. |
| Discernment | Critically evaluating AI output for accuracy, relevance, bias, and completeness. | Avoids blindly trusting incorrect or weak AI responses. |
| Diligence | Using AI responsibly, transparently, and accountably. | Supports ethical use, governance, and trust. |
| Generative AI | AI that creates new content such as text, code, images, summaries, or explanations. | Distinguishes creative AI systems from traditional classification systems. |
| Traditional AI | AI that usually analyzes, classifies, detects, predicts, or recommends using existing data. | Helps clarify what is new about generative AI. |
| Large Language Model | A generative AI model trained to understand and generate human language. | Core technology behind assistants like Claude. |
| Transformer Architecture | A neural network architecture that handles context across sequences effectively. | Major breakthrough behind modern LLMs. |
| Pre-training | Training a model on large amounts of data to learn broad language and pattern relationships. | Builds broad model capability. |
| Fine-tuning | Additional training to shape model behavior for usefulness, safety, or specific tasks. | Improves alignment with desired behavior. |
| Context Window | The amount of information a model can process at one time. | Affects long-document analysis and conversation memory. |
| Hallucination | A confident but incorrect or unsupported AI-generated output. | Major risk requiring validation and human oversight. |
| Knowledge Cutoff | The point after which a model may not know new events unless connected to current sources. | Important for current or time-sensitive questions. |
| Non-deterministic Behavior | The tendency of LLMs to produce different outputs for the same prompt. | Requires testing, evaluation, and tolerance for variation. |
| Product Description | Describing what output the AI should create. | Clarifies the desired result. |
| Process Description | Describing how the AI should approach the task. | Guides reasoning, method, and workflow. |
| Performance Description | Describing how the AI should behave during interaction. | Shapes tone, role, style, and collaboration quality. |
| Product Discernment | Evaluating the final AI output. | Checks accuracy, usefulness, and fit for purpose. |
| Process Discernment | Evaluating how AI reached its result. | Helps catch weak reasoning or skipped steps. |
| Performance Discernment | Evaluating the quality of the AI interaction. | Ensures the AI is adapting and communicating effectively. |
| Few-shot Prompting | Providing examples of desired input-output patterns in a prompt. | Helps the model follow a specific style or structure. |
| Chain-of-Thought Prompting | Asking or guiding the AI to reason through steps before answering. | Useful for complex tasks requiring structured reasoning. |
| Creation Diligence | Carefully choosing which AI systems to use and understanding training, data ownership, privacy, and suitability. | Helps prevent unsafe or inappropriate AI use before work begins. |
| Transparency Diligence | Being open about when and how AI contributed to work. | Builds trust in professional, academic, and personal contexts. |
| Deployment Diligence | Verifying and taking responsibility for AI-assisted outputs before using or sharing them. | Ensures facts, quality, fairness, and accountability are checked. |
| Accountability | Responsibility for the final impact of AI-assisted work. | AI assistance does not remove human or organizational responsibility. |
