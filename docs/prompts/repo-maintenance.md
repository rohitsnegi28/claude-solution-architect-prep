# Repository Maintenance Prompts

## Keep Docs Aligned

```text
Review the latest repository changes.
Update only the docs affected by those changes.
Keep canonical explanations in lesson files and use root files as concise summaries.
Refresh CHANGELOG.md, TODO.md, and CONTEXT_SNAPSHOT.md.
```

## Convert Notes Into Course Material

```text
Turn these notes into exam-ready Markdown.
Place them under the right course module.
Extract glossary terms, likely questions, quick revision notes, and architecture implications.
```

## Find Gaps

```text
Audit this learning workspace for missing concepts, weak explanations, stale TODOs, and duplicated content.
Return prioritized fixes, then implement the high-value documentation edits.
```
