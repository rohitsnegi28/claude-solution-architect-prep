# Study Workflow Troubleshooting

## Problem: New Chat Has No Context

Read `CONTEXT_SNAPSHOT.md`, then `TODO.md`, then `CHANGELOG.md`.

## Problem: Notes Feel Duplicated

Keep the detailed explanation in the lesson file. Replace repeated text elsewhere with a short summary and link.

## Problem: A Topic Is Hard To Revise

Add three things:

- a plain-language definition
- one architecture connection
- two likely questions

## Problem: Unsure Where New Content Belongs

- Lesson-level content goes in `course-modules/`.
- Broad exam aids go in `reference/`.
- Project memory goes in root files.
- Maintenance details go in `docs/`.
