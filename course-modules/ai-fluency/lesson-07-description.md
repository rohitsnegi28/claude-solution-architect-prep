# Lesson 07: Description

## Topic Overview

Description is the AI Fluency competency focused on communicating effectively with AI. The lesson emphasizes that AI should not be treated like a vending machine. Instead, users should create a clear thinking environment that helps the AI become a better partner.

## Learning Outcomes

By the end of this lesson, I should be able to:

- Define description as an AI Fluency competency.
- Explain product, process, and performance description.
- Improve AI outputs through clearer context, requirements, and expectations.
- Understand description as more than clever prompting.

## Three Components of Description

### 1. Product Description

Product description defines what you want the AI to create or provide.

It includes:

- Desired output.
- Required format.
- Target audience.
- Level of detail.
- Constraints and success criteria.

Example: Ask for a one-page executive summary in bullet points for non-technical stakeholders.

### 2. Process Description

Process description guides how the AI should approach the task.

It includes:

- Data or source material to use.
- Steps to follow.
- Methods or frameworks to apply.
- Examples to imitate.
- Checks to perform before answering.

Example: Ask the AI to compare options using cost, risk, feasibility, and business value.

### 3. Performance Description

Performance description defines how the AI should behave during the interaction.

It includes:

- Tone.
- Role.
- Conciseness or depth.
- Whether to challenge assumptions.
- Whether to ask clarifying questions.

Example: Ask the AI to act as a senior solution architect who is concise but flags risks clearly.

## Architecture / Solution Design Connection

Description maps to how prompts, user interfaces, templates, and system instructions are designed. Good AI systems make it easy for users to provide context, constraints, and desired outputs.

A solution architect should consider:

- What inputs the AI needs.
- How users will provide context.
- What prompt templates are reusable.
- How the system guides output format.
- How behavior expectations are encoded.

## Exam-Focused Takeaways

- Description is clear communication with AI.
- Product description = what output is needed.
- Process description = how AI should work.
- Performance description = how AI should behave.
- Better description improves relevance, quality, and alignment.
